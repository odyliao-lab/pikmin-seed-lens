# 皮克敏花苗透視鏡 0.18.1 預覽版

- 加入 Pikmin Bloom 158.0（1794902053）的遊戲內顯示設定，保留 157.0 的既有配對。
- 調整 158.0 花苗副標字級，讓名稱與兩位數庫存統計避開遊戲原有的步數和地名。
- 同一原簽章 APK 已在 MuMu Android 15／API 35 覆蓋安裝。實測通過花苗清單、育苗詳情、成年皮克敏副標、精華／花瓣對照、重開遊戲後自動套用，以及關閉後恢復原顯示。
