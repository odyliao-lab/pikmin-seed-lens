## 1 首次使用與精準診斷

全新安裝第一次開啟可選環境檢查或略過；已保存功能意願的舊使用者不再彈出。診斷頁列出 Root、平台、遊戲版本、內建檔案與下一步，回工具頁後沿原同意／動態套用流程。不自動取得 Root、不載入遊戲、不阻擋五個開關。

API32 仍沿原 su-c／PID1 mount namespace 守門；只有 exit6、完整且唯一 ROOT_NAMESPACE_MISMATCH 標記才顯示特定原因。其他錯誤碼6、截斷、雜訊、非API32均不能推定此原因。提示僅引導已使用 Magisk 者人工設定；不改 Root 管理器、不重開模擬器、不更換載入方式。

Root 結果只代表本次檢查；回到診斷或重新檢查環境會清除舊 Root 結果，須明確重新檢查。歷史 last_phase 不當目前已載入證據。命名空間細節僅本機顯示，上傳仍用原封閉 schema 的 denied_or_incompatible，不增加原始路徑／指令輸出，與現行服務相容。

驗證：DiagnosticPolicyTest 66項包含實際解析器正負例、精準提示、原上傳格式及舊ON不得當即時狀態；Android35 SDK 全Java編譯通過。尚未在 MuMu 實測 Magisk 各命名空間模式、首次畫面或拒權；不是新增 Root／遊戲資格。
