## 1 首次使用與精準診斷

全新安裝第一次開啟可選環境檢查或略過；已保存功能意願的舊使用者不再彈出。診斷頁列出 Root、平台、遊戲版本、內建檔案與下一步，回工具頁後沿原同意／動態套用流程。不自動取得 Root、不載入遊戲、不阻擋五個開關。

API32 仍沿原 su-c／PID1 mount namespace 守門；只有 exit6、完整且唯一 ROOT_NAMESPACE_MISMATCH 標記才顯示特定原因。其他錯誤碼6、截斷、雜訊、非API32均不能推定此原因。提示僅引導已使用 Magisk 者人工設定；不改 Root 管理器、不重開模擬器、不更換載入方式。

Root 結果只代表本次檢查；回到診斷或重新檢查環境會清除舊 Root 結果，須明確重新檢查。歷史 last_phase 不當目前已載入證據。命名空間細節僅本機顯示，上傳仍用原封閉 schema 的 denied_or_incompatible，不增加原始路徑／指令輸出，與現行服務相容。

驗證：DiagnosticPolicyTest 66項包含實際解析器正負例、精準提示、原上傳格式及舊ON不得當即時狀態；Android35 SDK 全Java編譯通過。尚未在 MuMu 實測 Magisk 各命名空間模式、首次畫面或拒權；不是新增 Root／遊戲資格。

## 4 通知列狀態與關閉全部

沿用 LensService，每四秒核對既有控制器與有時效的回報，通知文字相同不重送。只呈現固定狀態，不包含原始錯誤／座標／帳號；鎖屏仍隱藏。通知提供開啟 App 與關閉全部，後者呼叫原 LensController.allOff 持久意願／原生確認流程，Root 失敗保留 pending-OFF，不以停止服務冒充還原。無開機啟動、額外服務或外掛。

Android13以上首次啟用時可授予通知權限；拒絕不影響主頁開關或關閉全部，也不反覆要求。允許或拒絕後原開啟遊戲操作皆可繼續，通知由系統權限控制。

驗證：NotificationServiceTest 12項執行實際 service＋controller、替身 Android/Root，驗證 action、去重、敏感字串排除、Root失敗時保存OFF、通知拒絕與成功後服務退出；原控制器80項回歸通過。尚未實測 Android 通知抽屜、OS授權、背景點擊與遊戲還原；主機替身不能取代裝置驗收。

只在原開啟 App／啟用自動檢查入口判定，沒有額外排程器。失敗次數與最後嘗試／成功時間保存在獨立診斷程序偏好；連續失敗等5分鐘、30分鐘、24小時後，下次開啟App可再查。成功清除失敗次數，沿每日節奏；舊資料沒有失敗次數則維持原每日節奏。自動OFF不發起自動HTTP，手動仍可檢查。不能保存嘗試時間時不連線。

畫面區分快取版本、上次成功檢查時間與本次結果；本機較新、同版、新版與新版SDK不足分開。不把網路失敗說成最新版，不自動下載／安裝。索引URL、原簽章／SHA／防降版及安裝互斥不變。參考控制中心 main 9efa7cb 的UpdateCheckPolicy，沒有帶入核心更新／恢復交易。

驗證：LensUpdateTest 58項含退避邊界、關閉、時間倒退、舊資料、版本比較及既有下載／封裝守門；UpdateRetryTest 38項執行實際LensUpdater非同步worker，HTTP及偏好使用主機替身，覆蓋保存失敗、失敗後保留快取、重開讀取退避、成功重置、手動檢查、重入與安裝中拒絕。不是實際HTTP失敗、Android程序死亡或安裝驗收。
