# 遊戲 158.0 截圖庫存

0.17.0／code59 加入獨立的「截圖庫存」頁。它讀取 Pikmin Bloom 158.0 精華清單的單張截圖，把每張可辨識卡片的精華和花瓣數量並列。結果反映截圖當時的庫存。

1. 在遊戲隊伍畫面點精華球旁的數量，截下完整直式清單。
2. 開啟透視鏡「截圖庫存」→「選取清單截圖」，或從 Android 圖片分享選「透視鏡・截圖庫存」。
3. 點任一卡片對照原圖。捲到其他花種後可再選一張。模糊或被遮住的值顯示「待核對」。

辨識在獨立 Activity 中執行，使用 Android 選圖或分享授予的單圖讀取權限。圖片與結果只在本機處理。支援原尺寸直式 PNG、JPEG 或 WebP（16 MiB 以內）。建議保留篩選列及至少一整列花種。遊戲內的花苗、探險等即時顯示功能維持各自的既有版本資格。

## 驗收

- 隔離 MuMu Android 15／API35，Google Play 安裝的 Pikmin Bloom 158.0（1794902053）。透過系統選圖與「檔案 → 分享」各送同一張遊戲原尺寸清單，兩條路徑都辨識出 8 張卡片。
- 與原圖核對普通精華／花瓣 200／97、黃色 164／20、紅色 78／0、藍色 20／0。特殊精華的花瓣未顯示，辨識後保留「待核對」。點普通精華卡片可打開原圖並看到 200／97。
- 裝置用只含截圖辨識 Activity 與相同辨識程式的獨立測試 APK。完整 0.17.0 待原簽章覆蓋安裝、正式發布與舊版升級驗收。
- 純 Java 回歸覆蓋非庫存畫面、空數量欄、真零與缺值、缺少定位圖示和裁切不完整的卡片。手機與 API32 新版介面另待驗收。
