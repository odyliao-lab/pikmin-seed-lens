## 0.15.0 實測與修正原因

原簽章 0.15.0/code54 已安裝到 index4，保留既有 UID／設定與歷史。APK SHA256：`5ea0193c4cb75cfb393fe4f9c1ca5775346a2b81b86b8a76eda750c7f17a0e53`。此次交付後不覆寫同版，修正升為 0.15.1/code55。

- MuMu 12.0 實際為 API32、x86_64／libnb.so，遊戲 157.0/code1793360009。普通 App 的 Root 檢查通過；ADB 保持 shell UID2000。內建 su-c 與 PID1 掛載命名空間一致，不能聲稱重現了 Magisk 不符案例。
- 診斷不載入遊戲；顯示目前平台、精確遊戲版本與內建檔案核對。舊設定升級後沒有再次出現全新安裝導覽。
- 真實更新查詢取得公開 0.14.2，正確顯示本機較新，沒有降版下載／安裝。短暫關閉隔離機 Wi-Fi 時，ADB 同時失聯；使用該機 UI 完成離線查詢，再恢復 Wi-Fi。沒有重啟、修改主機網路或其他 guest。
- 離線後 `check_failures=1`，提示 5 分鐘後下次開 App 重試；原 manifest 雜湊與成功時間保留。強制結束並重開 App 後，嘗試時間／失敗次數不變。等待期後開啟 App 成功重查，次數歸零；手動查詢也成功。30 分鐘／24 小時級距仍是主機測試，未變更裝置時間來模擬。
- 遊戲未開時通知顯示等待遊戲；通知「關閉全部」保存五組 OFF，重開 App 仍為 OFF。遊戲內待種花苗已實際顯示種類、持有／育苗／待種數，通知關閉後恢復原名、原字級與原地點列。
- **找到缺陷**：背景通知停在等待畫面回報，雖然遊戲已顯示。`tick()` 先啟動 monitor、設定 active，隨後 `refreshReports()` 被跳過。0.15.1 改成先提交唯讀回報，再執行 monitor；讀取完成後即更新通知，服務銷毀後不再發布。主頁採相同讀取順序，保留原程序／時效守門。
- 新增無 Activity 的實際 service/controller 主機回歸，覆蓋新回報、過期回報與遊戲退出，通知測試由 12 增為 16 項。Root／Android 是替身，不能代替下列裝置回歸。
