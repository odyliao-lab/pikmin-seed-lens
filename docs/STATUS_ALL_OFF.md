# 執行狀態與關閉全部

2026-11-11；0.10.3/code40 開發候選，尚未合併或發布。僅增加執行狀態與關閉全部，四組唯讀功能及相容守門沿用既有實作。

## 行為

- 單頁頂端顯示等待遊戲、等待畫面回報、已套用至已回報畫面、核對未通過或需要重開遊戲。開關只代表保存意願。
- App 在前景每三秒只讀核對同 boot/PID/start 的回報；超過既有五秒時效即不顯示套用成功。等待卡片、沒有綁定、缺失或不完整回報不等同實際套用。
- 同組含未開過的詳細頁時，只指出已有畫面回報套用，其餘仍待回報，不宣稱整組樣本驗收通過。
- 確認遊戲不存在後，不把上次程序的警告當作現在的結果；原 barrier 與 UNKNOWN 歷史仍保留。程序身分輸出無效必須報錯，不能當作遊戲不存在。
- 關閉全部先同步保存 App 的 pending-OFF 與取消自動啟用意願，再停止自有服務。若先前操作尚未返回，排隊等它安全結束，不取消或重送原操作。原生操作在同一 lease 先驗證全部設定、寫四組 OFF 主意願，再同步八個成員並核對回讀。
- 只有完整成功回報才解除 pending；中斷／Root 失敗仍禁止 ON，重新開 App 或重試關閉全部後繼續完成 OFF。非法設定不覆寫、不假裝關閉成功。
- 設定保存與畫面還原分開呈現。回報未確認時顯示等待還原；不因按下按鈕就宣稱原文字與字型已還原。

## 驗證

- JVM：新增 25 項狀態／關閉回報測試，涵蓋過期、等待卡片、無綁定、部分畫面回報、Root／版本問題及不完整回報拒絕；原有 DisplayGroups 62、LensStatus 117 等回歸通過。
- Controller：26 項直接執行實際 LensController 的 host 測試（Android／Root 為 doubles），驗證核對操作尚未結束時排入 OFF、保存意願而不假裝已關閉、禁止晚到的啟用、中斷後重開 App 接續 OFF、失敗保留 pending 與 UNKNOWN barrier。
- 原生實際設定 writer：既有遷移與非法值／symlink 拒絕，新增四主值加八成員的 13 個中斷位置回復。WSL 本機使用 RAM 暫存 fixture；CI 使用 runner 暫存目錄，均只操作自有 fixture。
- 原簽章、雙 ABI 建置、APK 配對 SHA 與封裝檢查通過；不因此擴大裝置相容資格。
- 最終 0.10.3：只操作既有 index5 隔離 MuMu 15.0／API35／x86_64＋libnb，精確 Game157.0/code1793360009。原簽章升級、遊戲未開啟狀態、啟用後等待遊戲、App 自行載入、花苗實際名稱與統計、套用回報、一鍵全部 OFF、原名稱／原字級還原與 App 重開保存 OFF 均已觀察。
- 全部四主值 ON 的繼承狀態由按鈕改為 OFF；最終回讀四主值、八成員皆 OFF，pending／auto-arm 皆 false，自有服務停止。遊戲使用期間 adbd 為 UID2000，沒有手動注入或手動寫設定提供功能。
- 既有 46 份 journal 的 SHA 全不變，本輪三個不同遊戲程序各新增一份；最終全部遊戲 thread 的 TracerPid 為 0，無額外顯示模組。取證後恢復 adbd2000，正常關閉本輪隔離機；未操作原四台。
- 實際只開啟花苗頁，其他頁與全組還原回報仍可能等待，UI 不宣稱全組已還原。已確認的還原範圍為花苗可見卡片，不把所有 OFF 值當成四組遊戲畫面驗收。
