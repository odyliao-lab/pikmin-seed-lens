# 開關意願與實際套用

0.14.1/code52 預覽版，依使用者實際操作回饋，將五個開關改成 App 自有的持久選擇。Root、遊戲、版本或前一操作尚未就緒時，仍能 ON／OFF，不再灰掉或跳回舊值。條件核對與實際套用留給程式，狀態分開回報。

## 行為

- 點選先同步提交 App 私有偏好；成功後立即呈現選擇，背景工作不鎖住開關。儲存失敗會還原畫面並提示，不能假稱已保存。
- 第一次 ON 先保留選擇，再詢問自動套用與未知載入停止遊戲的同意；取消同意仍保留 ON，顯示等待確認，原生有效值保持 OFF。
- 區分已開啟／等待首次確認、Root／設定同步、相容環境、遊戲、畫面回報與需正常重開遊戲。ON 不代表已載入、複製或畫面驗收成功。
- 四組與 GPS 各自核對資格；GPS 不合格時可以保留 ON 意願，但有效控制保持 OFF，不因其 UI 可選而放寬平台。
- 關閉全部原子保存五項 OFF 與 pending-OFF。使用者之後仍可保存新 ON，但必須先取得舊關閉交易確認，才能同步新意願。
- 中途快速修改以修訂號隔離；舊回報不更新新選擇，過時交易停止後續寫入，依最後選擇補同步，不取消已開始的原生呼叫。
- Root／設定同步失敗仍保留本機選擇；設定同步間隔15秒重試或點狀態立即核對。遊戲程序與相容條件由現有前景服務動態核對，不從開機自啟。
- 原精確版本／digest／prologue／metadata、Root、NativeBridge、更新 interlock、程序身分與 UNKNOWN barrier 不變。條件不符時不載入、不把不確定載入排入重試。

## 遷移與資料

`lens-interface` 私有偏好的 `feature-intent-v1-0`～`4` 各對應四組與 GPS。只有尚未存在的意願才從獨立 App 既有 root 設定讀取；有效讀回後先提交本機意願，再補同步有效控制。明確本機 OFF 不會被舊 root ON 反向覆蓋。

非法／讀取失敗不當 OFF；損壞的本機值也不匯入 root 值，使用者可直接重新選擇以修復本機偏好。原生非法控制檔仍依原政策拒絕，不覆寫未知檔案。
